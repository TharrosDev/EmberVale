# Embervale 3D asset audit and visual QA

This is the permanent inspection entry point for production models. It is read-only: the audit
imports models into temporary Blender/Godot scenes and never saves or exports production assets.

## Run it

```powershell
python tools/audit_3d.py
python tools/audit_3d.py --render all
python tools/audit_3d.py --render selected --asset assets/models/characters/chr_player_base.glb
python tools/audit_3d.py --render selected --asset assets/models/characters/chr_player_base.glb --pose idle --pose movement --pose attack
```

The default report location is `reports/3d/session-1-foundation/`. `inventory.json` and
`findings.json` are the stable machine-readable entry points; the Markdown files are the review
surface. Blender is discovered from `PATH` and normal Windows installation locations. Godot is
discovered from `PATH` and the repository-documented local console path.

`--static-only` is useful in CI or a machine without Blender/Godot. It still checks payload
structure, hashes, materials, textures, import configuration, provenance candidates and repository
usage. A full run adds evaluated geometry hashes, world bounds, negative transforms, imported
clips/collision nodes, and truthful renders.

Godot `MeshInstance3D.get_aabb()` is authoritative for imported static meshes. A skinned mesh's raw
AABB is bind/skin-space and can be hundreds of metres before animation, so the probe records it as
`raw_skinned_*` evidence but marks `bounds_reliable: false`; rigged world dimensions and capsule
comparisons use Blender's evaluated geometry instead.

## Visual QA contract

`--render all` creates six diagnostic PNGs per production model: front, back, left, right, front
three-quarter and rear three-quarter. Renders include a ground plane, 1.8 m human reference,
bounding box and RGB origin axes. They are generated by Blender Eevee from the actual asset.

For a changed rigged model, render selected views, then inspect idle, movement, and attack/equipment
poses in Blender or the running Godot scene. The audit records available actions and imported clip
names; it does not pretend that an unresolved gameplay slot is a valid pose.

## Interpreting flags

Flags are triage evidence, not permission to edit. Before changing any shared resource, use the
inventory's `usage.files` list and trace its dependents. Collision heuristics deliberately report
visual and physical geometry separately. Import-scale corrections are recorded and preserved;
never normalize them blindly.

The source library under `assets/library/` is inventoried as provenance input but is not production
and is not sent through the production render batch. It remains protected by `.gdignore`.
