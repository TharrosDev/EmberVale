> **G2 ordering rule:** the compendium is a feature, so Phase 45A must decide its launch scope. If
> retained, Phase 45E implements/proves the Codex schema, unlock authority, persistence decision,
> panel foundation, validation and debug seam before feature freeze. If cut, this whole phase is
> skipped and lore books remain ordinary readable/quest content—no stub. Phase 50.5 is Beta catalogue,
> placement, presentation completion and content-coverage acceptance on the frozen foundation.

- [ ] **50.5A — G2 evidence recheck and content schema lock** [C/P]
  - **Build / Author:** confirm the signed Phase 45 matrix row, frozen categories/unlock rules/teaser policy,
    Bestiary boundary and saved-versus-derived ownership; inventory Phase 50 collectibles/story flags that
    can unlock entries. If the foundation is absent, stop and invoke 45K rather than building it here.
  - **Verify:** every planned unlock has one authoritative writer and no combat data duplicates Bestiary.
  - **Done when:** Beta work is content/presentation only and each entry has an owner.

- [ ] **50.5B — Compendium catalogue batch** [C]

    five guilds, companions and approved discoveries; localized teaser/full text; no Pale Concord spoiler.
  - **Verify:** LORE consistency, unlock timing, all Loc keys, category/id validation and duplicate writers.
  - **Done when:** the launch coverage matrix is complete with no unreachable or prematurely revealed entry.

- [ ] **50.5C — Collectible/story placement and unlock integration** [C]
  - **Build / Author:** wire Phase 50 lore books and existing story flags; choose world/map pin policy,
    duplicate pickup behavior and world-state variants; every collectible stays reachable after story changes.
  - **Verify:** pickup before/after relevant quest, duplicate/reload, hidden realm, map/reachability and save.
  - **Done when:** every entry has one reachable unlock or an intentional tested story gate.

- [ ] **50.5D — UI/content accessibility and completion acceptance** [P]
  - **Build / Author:** finish category/list/detail copy, locked/unread states and long-text presentation on
    the frozen panel; controller focus, text/UI scale, high contrast and locale expansion.
  - **Verify:** empty/partial/full catalogue, controller/mouse, max scale, long pseudo-locale and captures.
  - **Done when:** all scoped lore is readable, focus-safe and zero placeholder/untranslated entry remains.
