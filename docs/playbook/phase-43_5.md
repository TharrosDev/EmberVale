## Phase 43.5 — Flamebearer Vision Sequences `[F/C]`

> A vision is a Phase 43 presentation profile and trigger policy, never another director,
> timeline schema or save format. Boss defeat/corruption choice remain Phase 36/23 authority.

- [ ] **43.5A — Vision profile and transition grammar** `[F/P]`
  - **Goal:** a distinct accessible memory language.
  - **Build / Author:** reusable ash/desaturation, lens, audio and entry/exit profile; reduced-motion,
    high-contrast/subtitle behavior; player reflection keyed from current corruption tier.
  - **Verify:** all tiers/settings, skip/abort and arena return with no environment/audio leak.
  - **Done when:** a template vision is distinct and restores every presentation state.

- [ ] **43.5B — Boss-defeat trigger and exactly-once state** `[F]`
  - **Goal:** attach visions without stranding rewards or arenas.
  - **Build / Author:** validated boss→sequence id, trigger after combat/reward is safe, seen/completion
    flags and fallback; define reload across defeat slow-mo, corruption choice and vision.
  - **Verify:** defeat reload, skip, death/load transition, missing vision, already-seen and reward dedupe.
  - **Done when:** each vision runs at most once and cannot block the boss outcome.

- [ ] **43.5C — Iron King, Hollow Queen and Storm Tyrant visions** `[C/P]`
  - **Goal:** stage control-through-fear, stasis and vengeance as three different falls.
  - **Build / Author:** concise camera/block/dialogue/VFX/audio sequences with approved duration and
    Phase 53 asset handoffs; end on the player's reflection rather than exposition.
  - **Verify:** real hooks, natural/skip/reload, subtitles/locale and story-transition order.
  - **Done when:** all three communicate distinct failures from their boss arenas.

- [ ] **43.5D — Beast Lord, Crimson Prophet, Ashen Knight + set integration** `[C/P]`
  - **Goal:** complete corruption, worship and failed-final-battle memories.
  - **Build / Author:** final three sequences; Ashen Knight triggers only at Phase 49 final defeat.
    Matrix boss/realm/sequence/seen flag/reflection/next quest.
  - **Verify:** defeat orders, all seen combinations, save compatibility, optional cast, audio/subtitles.
  - **Done when:** the six-row matrix is complete and no vision changes the result it reveals.
