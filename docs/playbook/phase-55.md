## Phase 55 — G3 Content-Complete Acceptance Campaign [C/P]

> G3 requires all content/art/audio/text in and measurable reachability. Phase 55 is an acceptance
> campaign plus repair, not the first time anyone discovers whether the game can be finished.

- [ ] **55A — G3 inventory, route fixtures and defect thresholds** [P]
  - **Build / Author:** manifest all acts/endings/branches, realms, bosses, guilds, cult, companions, side systems,
    locations, items, codex, art/audio/Loc; create clean and branch-point save fixtures through legitimate play.
    Define Blocker/Critical/High as 45J; G3 permits bugs but zero placeholder/unreachable/missing-content rows.
  - **Done when:** every requirement has a route, fixture, expected flags and owner.

- [ ] **55B — Clean New Game through Act I/early Act II** [C/P]
  - **Verify:** onboarding, all verbs including ranged, Kael/corruption, first guild/cult opportunities, first realm
    transition, dangerous saves and no console dependency.
  - **Done when:** route completes and defects are triaged/fixed or assigned within G3 threshold.

- [ ] **55C — All five realm arcs and bosses campaign** [C/P]
  - **Verify:** approved order permutations, every realm route/map, bosses/visions/relic choices/world states,
    travel/mount/water, guild/cult hooks and save/reload before/after each transition.
  - **Done when:** every realm/boss outcome is reachable and flags/rewards remain coherent.

- [ ] **55D — Act III/IV and Dawnfire ending** [C/P]
  - **Verify:** reveals, rival duels, Celestial assault, final bosses, eligibility, Dawnfire, credits/postgame,
    epilogues and dangerous reload points.
  - **Done when:** one clean legitimate Dawnfire route completes with expected final vector.

- [ ] **55E — Lord of Embers and prerequisite-boundary campaign** [C/P]
  - **Verify:** legitimate corrupt route plus values immediately below/at/above each threshold, loyalty/alliance
    variants, finalization/credits/postgame and replay from safe branch fixture.
  - **Done when:** Ember route and unavailable-choice explanations match the state graph.

- [ ] **55F — Guild/cult/companion/side-system reachability** [C/P]
  - **Verify:** every guild terminal, cult state, companion recruit/loyalty quest, housing/economy/crafting/codex,
    lair/bounty/collectible and item unique; check refusal/absence/full party/full pack.
  - **Done when:** every optional content row is reachable or explicitly mutually exclusive with a tested alternative.

- [ ] **55G — Orphan, placeholder and inaccessible-content sweep** [C/P]
  - **Build / Author:** automated/manual searches for orphan flags/quests/dialogue/map ids, missing art/audio/text,
    procedural audio fallback, generic critical models, TODO/stub/placeholder and unreachable loot/recipes.
  - **Verify:** validators/negative tests, content manifests, map/quest reports and all coverage matrices.
  - **Done when:** zero unapproved placeholder, orphan, inaccessible row or missing localization key remains.

- [ ] **55H — G3 regression rerun and sign-off** [P]
  - **Verify:** rerun affected routes plus both ending smoke routes, all five world-quality gates, save matrix and
    performance sanity; zero Blocker/Critical and no High that makes content unreachable.
  - **Done when:** manifest is 100% present/reachable, both endings complete, art/audio/text coverage is complete
    and maintainer signs G3 evidence.

> **🚩 G3 — Beta / Content Complete.** All intended launch content is present and reachable; both endings
> complete; no placeholders. Remaining work is measured balance, defects, performance and release craft.
