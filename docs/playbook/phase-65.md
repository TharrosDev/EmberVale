## Phase 65 — Post-Launch Content (the long tail) [C/F]

> This is a portfolio of separately approved initiatives, not an automatic promise that every row ships.
> Each uses the base pipeline, G2-style feature review, G3 content campaign and G4 release evidence.

- [ ] **65A — Post-launch roadmap/governance and compatibility baseline** [P]
  - **Build / Author:** prioritize player problems/opportunities, budget/support/platform/localization needs and launch
    save/content compatibility; each initiative gets go/no-go, owner, dependencies and rollback.
  - **Done when:** no content announcement precedes feasibility/compatibility approval.

- [ ] **65B — New Game+ state-carry contract** [F]
  - **Build / Author:** explicit carry/reset/rederive table for identity/level/perks/gear/relics/corruption, quests/flags,
    guild/cult/companions, world/map/bosses/housing/economy/codex/achievements; fresh NG+ namespace/version and return policy.
  - **Verify:** both endings, minimal/maximal saves, unique rewards, hidden realm, repeated NG+ and old launch saves.
  - **Done when:** no stale quest/world flag leaks and every retained item/state is intentional.

- [ ] **65C — NG+ escalation and higher-difficulty content** [C/F]
  - **Build / Author:** only after 65B: data-driven enemy/loot/economy/progression escalation using frozen knobs; no unreadable
    telegraphs, mandatory corruption or exclusive story reward unless explicitly approved.
  - **Verify:** Phase 56 cohorts, all bosses/realms, companion/solo and save migration.
  - **Done when:** escalation creates new decisions rather than health inflation alone.

- [ ] **65D — Additional region/boss/content-drop pipeline** [C]
  - **Build / Author:** each approved drop uses region spec template/world-quality, map/travel/story unlock, encounters/NPCs/
    quests/rewards/art/audio/Loc/save and performance budgets; preserve empty land and non-swimming/cut-system contracts.
  - **Done when:** the drop passes a bounded G3/G4 campaign and base game remains unchanged when absent.

- [ ] **65E — Companion/guild/seasonal content policy** [C]
  - **Build / Author:** approved additions use existing loyalty/guild/event systems; define availability/end-of-season replay,
    rewards and offline behavior before authoring. Do not create FOMO schedules by default.
  - **Verify:** absent/expired content, saves, achievements, localization and reward duplication.
  - **Done when:** content remains recoverable/understandable and never blocks base progression.

- [ ] **65F — Post-launch release acceptance** [P]
  - **Verify:** target platforms, launch-save migrations, base-only install, optional content absent/present/update/rollback,
    performance/localization/accessibility/support notes.
  - **Done when:** every shipped drop is independently removable/rollback-safe within its declared compatibility contract.
